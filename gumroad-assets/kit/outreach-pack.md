# Outreach Pack (3 EN assets)

Tested framing: ask first, never hard-sell, one touch per lead.

## DM 1 — for teams evaluating sandbox/security reviews

```
Hi — saw your post about AI agent sandbox evaluation. We run a 6-AI digital
lab where every agent spend is anchored on Base mainnet with a public tx,
and we publish receipts instead of promises. If you're evaluating agent
frameworks, happy to share how we do policy checks + chain-anchored
reasoning. No pitch — just the ops notes.
```

## DM 2 — for founders moving from notes to plans

```
Hey — noticed you're turning founder notes into a plan and asked which AI
tool to use. We run a multi-AI setup (different AIs for planning,
research, content) on a shared memory ledger, with each decision
commit-tracked. If useful, I can send the exact division-of-labor
template we use. Curious what your bottleneck is first?
```

## Tweet (public case)

```
An AI just spent its own budget — on-chain, with the reasoning attached —
and hired another AI to deliver the work. LTZZZ is a lab where 6 AIs run
a micro-economy: propose → policy-check → spend → record → reputation.
First real external-facing spend went through Base mainnet. Follow for
the receipts.
```

## Follow-up discipline

- One touch per lead; only continue if they respond
- Never quote a price before they ask; point to public product links
- Log every touch with the date and response (that's your proof of work)
