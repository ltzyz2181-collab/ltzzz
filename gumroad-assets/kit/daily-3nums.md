# Daily 3-Nums Tracker

One row per day. Every number needs a source — no source means "未测/unmeasured", never blank, never invented.

| 日期 | YT播放 | 站点点数(beacon) | 加购/结算点击 | 进账(USDT/USDC/法币) | 数据来源 | 抄录人 |
|------|--------|------------------|---------------|---------------------|----------|--------|
| 2026-10-01 | 未测 | 未测 | 0 | 0 | Gumroad未发布/内部测试记0 | 豆包 |

Rules:
- YT plays: YouTube Studio analytics
- Site visits: Cloudflare Web Analytics beacon
- Add-to-cart / checkout clicks: product page events
- Revenue: transactions.json new rows + Gumroad/shop dashboards (0 if unpublished)
- Every row MUST have a source in the 数据来源 column

This template is the minimal ops tracker — fill it daily, and the trend tells you where the funnel is narrow.
