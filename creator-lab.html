创作实验室

使用多个 AI Agent 协作生产原创内容，发布到 YouTube / TikTok / 抖音 / 视频号，内容最终回流到 LTZZZ。核心思想：观 → 行深 → 改变习气 → 产生结果 → 再观。

多 Agent 生产架构

GPT 为总控 Agent；其余 Agent 可提出反对意见，任何 Agent 不得单方面改变总控架构。

GPT · 总控 Agent 判断主题 / 分配任务 / 综合四个 Agent 的结果 总控 · 不可擅改
豆包 Agent 中文短视频 / 抖音 / 视频号 / 中文内容 短视频脚本
DeepSeek Agent 研究 / 数据 / 长文 / 代码 / 资料整理 研究 / 事实
Grok Agent 海外热点 / TikTok / YouTube 海外趋势
Claude Agent 审稿 / 长文 / 代码 Review / 逻辑检查 审稿 / 反驳
治理规则：任何 Agent 都可以提出反对意见。修改 GPT 总控角色、Agent 权限或核心治理规则，必须进入 5 Agent 投票（GPT / 豆包 / DeepSeek / Grok / Claude），至少 3/5 同意才能形成修改提案，最终必须由用户确认。

内容生产流水线

输入一个主题，GPT 总控判断主题并分配任务，四个 Agent 并行生产，最后由 GPT 综合生成最终产出。

GPT 总控→ 豆包→ DeepSeek→ Grok→ Claude→ 综合产出
  1. GPT 总控：判断主题，分配任务
  2. 豆包：生成中文短视频版本
  3. DeepSeek：研究资料、事实、逻辑
  4. Grok：寻找海外相关讨论和趋势
  5. Claude：审稿、检查逻辑、提出反驳
  6. GPT 综合：汇总四个 Agent 的结果，生成最终产出
