人工传话

安全边界

  • 私钥、助记词、支付密码：不进网页、不进聊天、不进 AI「共管」。
  • 公共资金：人类多签（如 Safe 3/5）；单模型或单人热路径不能单独转走公共池。
  • API Key / Bot Token / 商户密钥：仅 Cloudflare Secret 等服务端。
  • 本页圆桌 = 流程演练；真调用走 Worker，真付款走已授权通道。
