# LTZZZ 智能合约框架（骨架）

本目录用于存放资金类 Web3 DApp 的智能合约。

## 当前状态

- 仅提供框架与接口设计，**尚未部署到任何网络**
- 后续会补充完整实现、测试与部署脚本

## 计划中的合约结构

```
contracts/
├── core/
│   ├── LabVault.sol          # 资金金库（存取、权限）
│   ├── ExperimentRegistry.sol # 实验注册与结果记录
│   └── AccessControl.sol     # 角色与权限
├── interfaces/
│   └── ILabVault.sol
└── mocks/
    └── MockERC20.sol
```

## 设计原则（对应「观 · 行深 · 魄 · 识神」）

1. **可观察（观）**：所有关键状态变更发出事件，方便前端与索引器读取
2. **可验证（行深）**：实验结果与资金操作均可被第三方验证
3. **风险控制**：资金相关操作需要多重确认或时间锁
4. **最小权限**：默认拒绝，按角色开放
