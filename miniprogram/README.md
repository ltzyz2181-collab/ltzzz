# 产品与服务展示小程序

本轮展示三项印章服务需求和两项 AI 工具说明。印章暂标面议，来源核对清单为免费技能说明，交付包验收仍为待上架候选；目录不证明任何平台已经审核、发布或开通支付。

原四个海外数字商品在 `data/products.js` 的 `legacyProducts` 中按原文保留，不参与本轮页面渲染。尤其 Muse 原来是治理参与凭证，不能仅改名成“资料包”就称其业务实质已改变或合规过审。将来确有不同的资料产品时另据真实交付内容和平台类目处理。

页面没有下单、收款、外链购买、文件自动交付或小程序内模型调用。门店地址当前仅为执行席转述，未在页面展示；使用前以真实商家资料核对。具体印章服务、材料和类目以实际经营和平台规则为准，不从企业名称推定经营资质。

沿用已澄清的真实小程序账号，在微信开发者工具核对主体、备案及当前版本后预览、真机体验，再按实际平台条件提审。公众号 AppID 不得充当小程序 AppID。游客模式可检查界面，真实上传仍使用现有受管的合法开发权限，密钥不入聊天或仓库。
