# 四产品展示小程序

可导入微信开发者工具的原生项目：四产品目录、详情、正确美元标价及交付说明。无付款、扣款、附件下载或外链跳转，不伪造微信商品审核或支付权限。

导入本目录，先用游客模式预览；上传时将 project.config.json 的 touristappid 替换为已核实的小程序 AppID。不能用公众号 AppID。实际上传需要该小程序的开发权限；miniprogram-ci 还需要对应上传私钥及 IP 白名单。

本目录提交不等于平台上传或上线。只有微信后台返回上传版本、体验版或发布状态后，才能记录相应结果。客户支付和数字交付功能未接入，不能将其宣称为已上线商城。

来源与商家上架资料：../content/commerce/four-product-listing-preparation.md。
