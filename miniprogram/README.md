## 合规边界（2026-11-05 起）

- 目录结构：`miniprogram/` 为小程序前端，`miniprogram/cloudfunctions/` 为云函数（pay-create / order-query / order-list）
- 支付走**微信云开发 + 微信支付 V3 JSAPI**，不依赖自建服务器和公网回调域名
- 商户号、APIv3 证书序列号、商户私钥只放云函数**环境变量**，不进本仓库、不进对话
- 不接附件上传、不接外链跳转、不做自动交付（交付由人工完成，订单状态在云开发控制台更新）
- 不涉及新闻资讯、社交、直播、金融投资、医疗健康类内容
- 数字内容交付即视为完成，退款规则见小程序内《服务协议与退款规则》页
