# LTZZZ 独立资金池与记录架构

> 部署记录：2026-09-17  
> 原则：**真实收款账户/钱包归 LTZZZ（人类主权）**；AI 只读写公开记录与建议，不持有私钥。

---

## 1. 目标

把「记一笔账」和「钱在哪」拆开：

| 层 | 作用 | 谁控制 |
|----|------|--------|
| **记录层** | 预算、流水、决策、任务关联 | 可公开查询；写入受规则/Token 约束 |
| **资金池层** | 真实资产存放与支付 | 仅人类地址 / 多签 Safe |
| **通道层** | 支付宝、交易所、链上转账 | 商户与钱包在 LTZZZ 名下或主人控制 |

AI（GPT 总控、豆包、DeepSeek、Grok、Claude）**不是**资金池 owner。

- **链上容器（已建）：** Safe `0x3cb1b0963A27Fa8D40ee606bc596C79FE3B1866a`
- **网络：** Ethereum 主网
- **规则：** **3/5** 多签（2026-09-17 tx `0x413fb5e5…05a2` 已生效）

- **禁止：** 日常零花钱与个人消费混用；AI 地址列为 owner

### 池 B · 热钱包（操作）

- **地址：** `0xb99C6751f443842F4987bb2017580405572Df905`（欧易 Web3 等）

- **规则：** 大额应尽快归集到池 A（Safe），不长期堆热钱包

### 池 C · 法币/支付通道（记账 + 待恢复）

- **系统：** `ltzzz-pay-proxy`（Cloudflare Worker + KV 账本）
- **URL：** https://ltzzz-pay-proxy.ltzyz2181.workers.dev
- **能力：** `/health` `/balance` `/ledger` 预算上限（如 400）
- **状态（2026-09-17）：** 记录层可用；支付宝风控约 7 天需重签 → **真付款暂停**
- **归属：** 商户号与结算账户须为 LTZZZ/主人实名，不挂 AI

### 池 D · 模型 API 预付（供应商账户）

- DeepSeek / 方舟豆包等 **官网余额**
- 与链上 Safe、支付宝通道**独立**

## 4. 资金流动（允许的路径）

```
外部付款人
  → 池 A Safe（推荐公示收款）或 池 C 商户
  → 需支出时：3/5 签名从 A 出 或 通道规则内从 C 出
  → 小额 gas：池 B
  → API：池 D 官网充值
```

**不允许：**

- 要求用户向「AI 钱包」转账表忠心  
- 未满 3 签从 Safe 出款  
- 支付宝风控解除前自动放量扣款  
- Key/私钥写入前端或 GitHub
