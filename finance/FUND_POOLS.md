# LTZZZ 独立资金池与记录架构

> 部署说明：本文是**治理与记账架构**，不是把私钥交给 AI。
> 真实收款账户 / 钱包 **归 LTZZZ 人类主权者**；AI 只读规则与公开账本摘要。

最后更新：2026-09-17

---

## 1. 原则

| 原则 | 说明 |
|------|------|
| 人持钥 | 私钥、助记词、商户号、支付密码只在人类侧 |
| 池隔离 | 不同用途的钱分地址或分账本科目，避免混用 |
| 先记后付 | 有预算与记录，再授权支付 |
| 链上共管可选 | 大额/共管资金进 Safe；小额运营可走个人热钱包但须记账 |
| AI 边界 | AI 可写提案、更新 Markdown、读公开 `/ledger`；**不能**成为 Safe owner，不能要求转「AI 钱包」 |

## 4. 钱怎么进、怎么出（流程）

```
收入 → 记入对应池（地址或科目）→ 公开/内部账本一条
     → 支出提案（用途、金额、池）→ 人类授权
     → 若 POOL-SAFE：Safe 提议 → ≥3 签名 → 执行
     → 若 POOL-OPS：热钱包直接付 + 账本记录
     → 若 POOL-FIAT-CN：商户可用后走 pay-proxy 规则
```

**硬规则（与 pay-proxy / budgets 一致）：**

1. 超预算停止  
2. 无人工授权不扩大额度  
3. 密钥不进 GitHub / 前端 / 聊天  
4. 支付宝风控解除并重签前，不启用自动转账
