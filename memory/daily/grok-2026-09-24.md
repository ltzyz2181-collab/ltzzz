## APP / Web3 代码审查

### 发现的真实改进点

`treasury-queue-worker.js` 当前对 `POST /queue/submit` 与 `POST /queue/execute` 使用 `LTZZZ_AGENT_TOKEN` 鉴权，但 `GET /queue/list` 未经过同一鉴权门。该接口会返回队列中的收款地址、金额、用途和状态；即使没有私钥，也属于不必要的信息暴露和可维护性不一致。

### 本次处理

本次没有直接改生产代码：当前 GitHub 读取结果未提供可安全用于覆盖的完整 blob SHA/发布验证链，避免误覆盖 Treasury Worker。建议的最小修改是：

```js
if (path === '/queue/list' && request.method === 'GET') {
  const gate = requireAuth(env, request);
  if (!gate.ok) return json(gate, 401);
  return await listQueue(env, url);
}
```

并将 `limit` 约束为 `Math.min(Number(...), 100)`，防止过大读取。
