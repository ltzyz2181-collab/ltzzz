# LTZZZ Memory Engine · 记忆中心

## 五大中心
1. Memory Center：长期记忆、重要决定、装备论、项目历史、重要事件、梦境与文明研究。
2. Task Center：任务队列、每日任务、验收标准、失败原因、下一步。
3. Asset Center：文章、代码、视频、研究、发布记录。
4. AI Center：每个 AI 的能力、凭证状态、真实测试、失败记录。
5. Result Center：任务 → 执行 → 实际结果 → 验证 → 数据 → 下一步。

所有接入 LTZZZ 的 AI 在执行长期任务前，必须先读取：
- ltzzz-memory/README.md
- ltzzz-memory/重要事件.md
- ltzzz-memory/项目历史.md
- ltzzz-memory/装备论.md

- 当日/昨日的 Memory、Task、Result 摘要

如果内容过大，先读取 manifest/index，再按任务相关性读取全文；不能声称“读过”未实际读取的文件。

## 记忆分层
- L0：安全规则、永久约束
- L1：重要决定与长期事实
- L2：装备论/魄/识神/梦境/文明等知识
- L3：每日记录
- L4：临时任务上下文

## 写入规则
AI 可以提出记忆更新，但高影响决定、资金、安全、账号权限等必须人工确认。

## 真实性
- proposed ≠ applied
- planned ≠ deployed
- API存在 ≠ API已验证
- AI回复 ≠ 实际结果

所有结果进入 Result Center 后才能成为“已验证”。
