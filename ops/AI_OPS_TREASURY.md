# LTZZZ 运营资金规程（重中之重）

主令：运营与小额资金由 AI 在规程内自主支配，服务自动化与自筹，不与「普通网站人工逐笔点转」同构。

## 1. 两池

| 池 | 用途 | 支配 |
|----|------|------|
| **运营小额池 Ops Float** | API、推广、实验、小额采购、测试上链 | AI 按策略自动提案并在限额内执行/出队 |
| **金库主池 Treasury** | 大额储备、捐赠本金、未分配利润 | Safe；超限必须多签/主人确认 |

## 2. 小额池默认参数（可改配置，不改主权叙事）

写入 `agent-pay-policy.json` 的 ops 段：

- `mode`: `policy-auto`（小额默认自动）
- 单笔上限：例如 ≤ 20 USD 或等值 USDT
- 日累计：例如 ≤ 50 USD
- 月累计：例如 ≤ 300 USD
- 网络白名单：Ethereum / 主人指定 L2
- 资产白名单：USDT / USDC
- 收款白名单：已登记供应商、广告、云账单、实验地址
- 每笔：提案 → 记队列 → 执行 → TxHash → `wallet/transactions.md` → Memory

超限：进入主池流程（多 AI 确认 + 主人/Safe）。

## 3. 执行链（自动化，不是人工客服）

```
需求/账单
  → AI 提案（用途、金额、网络、收款方）
  → Policy 校验（限额/白名单/网络）
  → Transaction Queue
  → 小额：Allowance/模块自动执行 或 主人一键签名队列
  → TxHash
  → 账本 + Memory
```

没有私钥进模型、进聊天、进公开仓库。执行端是 Safe / 主人钱包 / 托管 API，AI 管策略与队列。

## 4. 与「转 10 元」类指令

链上转账必须由**持有该网络资产的钱包**签名。AI/XAI/豆包都不能从空气转出。

1. 钱包 App 选 **USDT · ERC20 · Ethereum**，收款：`0x1893A134aa6eA22E8C08518B559E1706f4Da0eF7`，金额按显示，确认发送  
2. 或把该地址列入小额池白名单 + 充值小额池，由队列按规程自动出
