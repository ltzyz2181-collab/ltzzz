### 4.1 欧易 Web3 钱包 DeFi → ✅ 允许（唯一合规路径）

1. **WEP3 Worker** `/market/aave/*`（`status` / `preview` / `execute` / `reconcile`）——签名与合约护栏都在 Worker 内；或
2. **invest-channel `LTZZZVault.allocate(strategyId, amount)`**——合约带 `onlyAuthorized` / `whenNotPaused` / `whenNotVetoed` / `ForbiddenTarget` revert / 日限。

### 4.2 欧易交易所 CEX 现货 → ⛔ 拒绝（BLOCK-5）

v1 写了 `BTC-USDT` 市价买入并可被武装执行。**这违反章程 §1 与 §6**：BTC-USDT 不在白名单（白名单只有 Aave V3 Base 的 USDC），而执行席无权扩白名单。
