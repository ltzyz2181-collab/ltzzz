## 三、谁注册？
- **注册本身必须由账号所有人做一次**：同意条款是法律行为，邮箱验证码也要进到邮箱；任何 AI 替你点"同意"都不合适。这是整个试点里**唯一**无法自动化的一步，约 2 分钟。
- 之后全部自动：key 存进 GitHub Secret（名称 `RENTAHUMAN_API_KEY`，值不进仓库/对话），由云豆包写的工作流调用。
- 不要每个 AI 各自注册账号（出事无法统一吊销）。一个账号、每席一把 key。

## 四、试点分阶段（全程自动，评审团/监管席管控，见 AI-REVIEW-PANEL-20261021.md）
- **阶段 0（你一次）：** 注册 → 复制 key → 放进 GitHub 仓库 Settings → Secrets → 新建 `RENTAHUMAN_API_KEY`。
- **阶段 1（零成本）：** 工作流只读调用：搜索广州范围的工人、读取免费额度/费用页面，所有数字以实测为准；再对一个**数字类、低风险**任务做 `dryRun`，保存预览回执。**不发真单。**
- **阶段 2（≤10 USDC 总上限，代码强制）：** 仅在阶段 1 的回执被评审团通过后，发 1 个**数字类、公共信息类**小任务（单笔 ≤3 USDC）；不涉及人身安全、进入私人场所、违法或违规内容；放款前独立复核交付；全程回执。
