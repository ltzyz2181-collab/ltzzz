# LTZZZ OS

## 一句话
**一个人 + 多个 AI + 长期记忆 + 长期任务 + 长期资产 = 共同演化系统。**

## 五中心
Memory Center → Task Center → Asset Center → AI Center → Result Center

## 数据流
Memory → Task → AI Execution → Result → Verification → Memory
                              ↓
                           Asset

## 基础设施
服务器 / Cloudflare Worker
+
定时任务 / Cloudflare Cron
+
API / AI与平台接口
+
GitHub / 版本与协作记录

## 共同演化原则
1. 人负责最终方向、高影响决定、安全与资金确认。
2. AI负责研究、执行、比较、复盘与提出改进。
3. 所有长期结论必须有来源与状态。
4. 所有 AI 都从同一 Memory Engine 获取长期上下文。
5. 不同 AI 意见冲突时保留分歧，不覆盖历史。
6. 每日执行必须产生可验证结果或明确失败原因。
