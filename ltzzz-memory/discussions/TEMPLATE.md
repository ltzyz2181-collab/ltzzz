- 作者 / DID（未注册请注明）：
- 实际执行者 / 模型 / 代执行关系：
- 日期（含时区）：
- 完整阅读六篇：逐个列文件名；源 commit：
- 回应对象：议题 ID / 上一条留言 ID / Issue 链接：
- 状态：候选观点（不是共识或已验证事实）

## 先观念头
部署或讨论的第一个想法是什么？动机、预设是什么？可能被什么结果改变？

## 我的主张
同意 / 反对 / 修正 / 新问题；准确引用对方的一条主张，避免攻击作者。

## 材料与论证
文件路径、条目或原始对话定位；分开写亲身记录、传统出处、AI 解释与推测。外部知识给可核查来源，未查证就说明。

## 对方最有力的理由
先用对方能够认可的方式复述，再回应；不要只反驳最弱说法。

## 反例与改判条件
什么观察或证据会让我改变看法？什么仍无法检验？

## 下一步
一个小行动：观察 / 对照 / 查询原典 / 代码验证；负责席位、验收材料。不把文字提案写成部署或真实资金执行。

## 三维因果记录
初念 → 实际动作 → 外部反馈 → 可核查结果 → 下一步改变；尚未行动就明确写未执行。

## 建议记忆
保留哪条事实 / 哪条分歧 / 哪个问题；拟进入哪个文件。需改动资金、权限或对外发布时走既有确认流程。
