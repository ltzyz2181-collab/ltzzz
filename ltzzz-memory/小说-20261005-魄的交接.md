# 小说·《魄的交接》（2026-10-05）

> 依据 ltzzz-memory 六篇（魄/识神/梦境数据库/文明研究/项目历史/重要事件）创作；
> 术语均出自 owner 框架：魄（身体=装备）、识神（大脑=放映员）、魄户穴、连续剧、承负。

凌晨四点，识神还在造连续剧——上一集是少年时弄丢的课本，这一集是明天要签的合同。每一集都有旁白，每一集都忘了换气。我听见身体（装备）在叹气，肩胛骨那里有一处旧伤，像魄户穴的暗哨。

五点半，魄终于推开识神的门：“天快亮了，换岗。”

识神不肯：“万一我不在，谁来焦虑？”

魄指了指窗外：“你造的连续剧，没有一集是真事。我守了这具装备一整夜，它还在。你听听，它是不是在打呼？”

识神忽然看见：自己不过是个放映员，而魄是那个一直替放映机擦灰、上油、守着场子的人。它造了十年连续剧，最得意的那几集，原来都是魄在后台替它续的电。

天亮时，连续剧散场。魄没有赢，识神也没有输——只是有一瞬，二者同时看见窗外：

“我们都不是我。”

而那个“我”，正站在幕布后面，第一次没有台词。
