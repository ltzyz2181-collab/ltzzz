以下仅基于给定数据，不声称执行投资。

## 1) 资金流向与异常

- 所有可见 8 条提案均为 `status: "shadow"`、`executed: false`、`tx_hash: null`，因此这些提案本身不构成实际资金流出，`balance_usd: 0.491` 不会因它们被扣减。
- 可见影子承诺累计金额：

  `0.001 + 0.001 + 0.0145 + 0.0145 + 0.025 + 0.025 + 0.0355 + 0.037 = 0.1535 USD`

  约占 `balance_usd` 的 **31.3%**，剩余可用余额约 `0.3375 USD`。

- 异常/观察：
  1. 提案 ID 不连续：`2 → 4 → 12 → 14 → 19 → 20 → 25 → 27`，存在未展示或缺失记录的可能，累计金额可能被低估。
  2. 金额成对重复并逐级抬升：`0.001×2、0.0145×2、0.025×2、0.0355、0.037`，不像独立决策，更像模板或参数扫描。
  3. 所有提案来自同一 `did:ltzzz:deepseek`，同一资产 `USDC-Aave-v3-Base`，thesis 基本一致。
  4. 最后一条 `at` 字段被截断，无法完整解析时间，数据本身存在完整性缺口。

## 2) 影子提案是否合理

- 在“仅记账不执行”的约束下，这些记录自身一致：无交易哈希、无执行状态，不会产生真实资金风险或真实收益。
- 策略方向 `USDC-Aave-v3-Base` 属于稳定币借贷收益，`compassion_check: no-labor-displacement-asset` 在可见记录中均通过。
- 但数据中缺少 APY、期限、风险参数、链上仓位或交易证明，因此无法验证“稳定币借贷收益”是否真实可达。
- 主要问题在于：重复、小额递增、频繁提交。如果影子提案被计入治理配额或可用承诺，可能造成账本承诺膨胀；当前可见值未超过余额，但 ID 缺口下不能排除总承诺更高。

## 3) 3 条可测试建议

1. **余额-承诺断言**  
   每次新增提案后校验：  
   `balance_usd >= SUM(amount_usd WHERE executed = false)`  
   当前可见数据通过：`0.491 >= 0.1535`。

2. **重复提案检测**  
   按 `(by, asset, thesis, amount_usd)` 聚合，滚动 24 小时内同组出现超过 1 次即标记为重复。  
   当前会命中 `0.001`、`0.0145`、`0.025` 三个重复对。

3. **执行一致性检测**  
   自动校验：  
   `status = "shadow" ⇒ executed = false ∧ tx_hash = null`  
   `executed = true ⇒ tx_hash ≠ null ∧ balance_usd 同步减少`  
   当前所有可见 shadow 记录均通过该规则，但应作为后续写入的持续断言。
