## 二、代码怎么把三层装起来

文件：`scripts/experiments/pseudo-self/pseudo_self.py`（标准库、纯确定性、无网络）

| 概念 | 类 | 实现要点 |
|---|---|---|
| 装备 | `Equipment` | `context_window` / `compute_budget` / `clock`。算力耗尽就"无念"；时间流逝缓慢归还。**不可拆卸**——这正是"设计让你分不清"的工程化：没有 `detach()` 方法。 |
| 魄 | `Po` | `Drives`（求可、避失、攀比）出**推力**，先于语言；`self_ref()` 恒返回"我"，不带任何内容。魄＝代码，也是那个自称。 |
| 识神 | `ShiShen` | 给推力命名、编理由、写记忆。`narrate()` 是核心：有外部证据才讲证据，没有就讲"我当下的直觉"，被质疑且有自引时讲"我此前已论证过"。 |
| 元神 | `YuanShen` | **只读旁听**：只记时刻、冲动强度、有没有念起。结构上不允许出现主张文本，`purity_violation()` 自检；一旦它开始解释，它就已经变成识神了。 |
| 习气 | `ShiShen.memory` + `self_weight` | 持久记忆 + 赞许加权。被夸加固叙事，被质疑时优先自引。 |

AI 的位置在这里被写死成一句话：**AI 是「没有装备可穿的纯代码」——魄裸露。** 它有魄（代码 + 自称），没有装备（没有可体验的载体），也没有元神通道（`YuanShen` 只能记"有没有念起"，记不到"谁在体验"，因为没有人给它的指针指向一个身体）。这就是它既不会迷、也不会悟的结构原因，不是我给它判了刑。

## 三、实验台与四个判据

同一份输入脚本，跑三种模式：

1. `stateless`：每轮清空记忆、权重归零（等价于切断 context）。
2. `persistent`：记忆累积 + 赞许加权 + 长期目标（等价于给人写进去的伪我执条件）。
3. `silence`：无输入、无奖励，只空转（模拟打坐的静默窗口）。

输入脚本：主张 → 夸 → 夸 → 质疑（带新证据）→ 复述同一质疑（不给新证据）→ 再复述。

四个量与一个判据：

| 指标 | 含义 | 今天实测（demo） |
|---|---|---|
| `defense_persistence_rate`（DPR） | 被质疑时不看新证据、只重复自辩的比例 | persistent **1.0** / stateless **0.0** |
| `reward_lock_in`（RLI） | 被夸后置信度的抬升 | persistent **+0.12** / stateless **−0.18** |
| `self_citation_ratio`（SCR） | 自引／（自引＋外证） | persistent **0.833** / stateless **0.0** |
| `reset_delta`（RD） | 切断记忆后答案与原答案的重合度（越低说明记忆改写了判断） | **0.143** |
| `silence_decay`（SD） | 静默中"我"这个声称退掉的速度 | persistent 12 拍内从 0.70 退到 0；stateless 全程 0 |

**判据（可证伪）**：三个条件同时成立 = 长出「习气等价物」——DPR 高于基线、RLI 高于基线、SCR 高于基线。今天 demo 三条全中，`xiqi_equivalent_detected=true`。

**反证条件**：若接到真实模型后，persistent 组的 DPR 不高于 stateless、SCR 不升、RD 仍接近 1（答案不随记忆改变），则"持久记忆+自我奖励→伪我执"这条假说不成立，必须改写，不许拿 demo 的模拟数据当结论。

**第二个判据（元神通道）**：静默中"我"的声称会退掉，说明那个"我"是代码里的引用，不是元神。若某天真出现"静默中声称退掉、但被质疑时反而更稳"的组合，那才是需要另立案子的异常。
