## 密钥与算法先决条件

现有 `scripts/lib/patchgate.mjs` 的信任根/验签只接受 **Ed25519**；“云支持 KMS”不能推出其 KMS 能直接签现有载荷。本轮未取得阿里/火山目标区域和具体密钥产品支持 Ed25519 的正式兼容证据，**不得宣称 `KMS.Sign` 可直接替换当前签名函数**。

每家云执行器必须在公开回执中选择并举证以下路径之一：

- 目标产品确实支持所需 Ed25519：在供应商云内创建不可导出的签名 key，仅固定服务身份可调用签名，向总控交公钥/SPKI 与公开算法/版本资料；不能从 GPT runner 生成再导入。
- 不支持 Ed25519：在该云的隔离签名服务内生成并保管 Ed25519，API 永不返回私钥；明确说明其存储是否可导出、谁能修改服务/读取存储、管理员剩余能力，不把“API 不返回”包装成 HSM 不可导出。不能证明这些控制时继续阻断。
- 若改用云原生 RSA/ECDSA：另提签名算法、编码、摘要语义、信任配置和验签迁移 PR，独立审计后再走；本任务不静默更换算法。

公开导出的只有公钥、算法标识、公开 key/version ID 与证明摘要，不含私钥、AccessKey、OIDC JWT、认证头或完整模型密钥配置。

## 两家云分别执行的步骤

这份步骤是待执行接力，不是已执行命令记录。以下资源 API 的准确名称、区域支持和权限动作需各云执行器按其实际产品的官方文档核验，本轮不编造可成功运行的 CLI 命令。

1. **证实真正执行身份。** 千问卡由阿里云受管执行器、豆包卡由火山云受管执行器提交认领，沿用原任务号，记录 provider/account 的公开可核验标识、region、runtime、服务角色。模型回复“我有权限”不算认证元数据。
2. **建立隔离权限。** GPT/GitHub 发布方只可提交已审代码和读公开证明，不可 `CreateKey`、`Sign`、取私钥、改变签名服务 IAM 或密钥策略。每家 runtime 只持自己的模型调用能力与受限签名能力，不取得另一家的权限。密钥管理员、代码发布者、签名 runtime 的角色必须分别列出；如一个身份仍能修改代码并直接签任意输入，就准确写未隔离。
3. **固定已审发布物。** 输入必须是已审计 main 完整 SHA；在可信构建器产生包含全部运行时依赖的公开 release manifest（逐文件原字节 SHA256、包摘要、build/run ID）。源码哈希由 manifest 定义，不靠模型填写；签名不能包含自己文件的整体摘要形成循环依赖。
4. **云内生成/保管 key。** 按已核实的算法路径完成 key 创建，保存控制面操作回执与仅公钥导出记录。不让 GPT、通用 runner、另一模型席或模型上下文拿到私钥。
5. **部署默认关闭服务。** 云部署器读取确切发布物，检查其主线/审计和摘要； `/attest` 接口云中立，校验受信 GitHub OIDC、固定 task/provider/role、源码摘要、工件和预算。真实 provider 响应完成之前不能签；预留/幂等/未知失败不重放策略也在云端持久化。
6. **独立发布读回。** 用只读控制面执行器回读实际 service/version、运行包 code digest、IAM/版本路由，确认部署的是上述 release。证明必须有另一条可回读来源，不能只来自签名服务自己返回的 `source_sha256`。如云没有可核对 code digest/发布证据，M1 的强保证仍未闭环。
7. **重启挑战。** 在不轮换 key 的前提下，分别重启/创建新实例，用 fresh nonce 与 OIDC 身份再签挑战；公钥不变，部署版本、源码摘要、nonce、request run/attempt、时间都绑定。仅 HTTP 200 或首次进程内测试不能算持久性验收。
8. **一次原生调用与验签。** 各自服务读取同一任务的确切证据、留预留、调用自己的原生 provider，再签其真实响应。回执分别记录 provider/model/response ID、input/output/artifact/source hash、key ID、原始 verdict、签名、API 用量/未知账单。验证器按登记公钥与允许源码摘要验签；原生输出拒绝必须保留。`paid=false` 指无订单/链上结算，不能宣传模型调用免费。
9. **交独立审计。** 两份公开回执与确切代码 head 一并交 Claude 与另一实际提供商复核。登记服务/公钥/源码摘要和启用是不同阶段，先可默认关闭登记；缺实际公钥就留 null，不造假。作者/检查生产端、#246 首次合并验收及启用提交另按原单推进；A2/A3/B/资金不因本卡而开启。
