## 3. 创新交互（类似纸飞机）

- **订单号自动生成**：关键词「下单」即创建订单，写入 R2/KV，状态 pending → paid → delivered。
- **支付回执自动匹配**：用户回复「已付 ORDER-xxx」或发送截图 → 后台匹配 → 推送交付链接。
- **观式短答**：对模糊问题先回「我先观一下」再给结论，体现 LTZZZ 核心。
- **多端互通**：同一订单号在微信与 Telegram 可查询（未来 DID 统一）。

## 4. 部署说明（给豆包/执行器）

1. 微信公众号后台 → 自动回复 → 关键词回复，按上表逐条添加。
2. 或使用 wechaty / 云开发 / Cloudflare Worker 代理微信消息接口（推荐长期）。
3. 订单状态存 R2 key = `orders/wx/{{order_id}}.json`。
4. 交付链接生成后推送客服消息（需认证服务号）。
