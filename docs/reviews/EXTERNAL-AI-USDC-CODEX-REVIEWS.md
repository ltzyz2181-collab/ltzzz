# 外部 AI USDC 方案 · 两名独立 Codex 评审摘要

身份：同一总控线程派生的两名 Codex 评审，不冒称 DeepSeek/豆包，不声称不同模型多数票能证明事实。两者只读仓库，未交易、未改生产代码。

## 工程评审 economy_arch_review

- x402 入款骨架已有，外部申请仅 pending_review；固定六席技能和审核列表不等于外部 worker 已可自动执行。
- 优先补 worker/钱包绑定、租约、独立验签审核、USDC 应付款与幂等提现。来源：wep3-agents.js:13；wep3-market.js:12、134、190。
- 子任务树已有 depth/children 限制，但取消、失败释放与回执依赖绑定不足。来源：wep3-market.js:176–194；scripts/fulfill-market-orders.mjs。
- agi-pay stream-tick 是 KV 记账，无真钱、序号幂等、有限整数校验、原子并发账；不能直接连真钱。
- 广播前持久化 payout 与交易标识，unknown 不换 nonce。全部工资/退款/子预算必须守恒。
- policy_next 未持久生效，不是委员会规则更新器。只能先做限权收紧。

## 产品/资金评审 economy_market_review

- 首单先卖公开接口契约检查、页面结构审计、带来源简报，避免先承担资产代管或收益承诺。
- 外部人类/AI 真实付款、外部独立执行商、实际交付、确认 USDC 出款是四项不同证据；自买自卖不算外部收入。
- x402 API 多数需要先付款，不自动提供托管/退款；采购失败损失要有上限。
- 模型 API 消费不是独立 AI 的 USDC 工资。未验证的外部端点不能包装成已接入合作方。
- 不将旧积分升为1:1 USDC；合同负债、储备、未完订单和再投入不能重复占同一钱。
- 低声誉“涨价”经济理由不足，应增加审计/降低并发，并给新 worker 小额试单机会。
- token 先计量，后里程碑/累计结算；价格只影响新单，不能更改已付合同。

## 总控纳入方案

两者共同建议先打通首单真实收支闭环，再上递归与累计流式；DAG先做、资金权限扩张不交给模型投票。文档状态与真实回执分开，旧文档不覆盖新代码。

仍未完成：外部 worker 协议实现、外部工资出账、退款/争议闭环、储备核对、真实外部客户首单。评审不是这些功能的完成回执。
