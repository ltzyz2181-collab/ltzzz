## 四、三个硬卡点（按阻断强度排序）

### 卡点 1：商户平台没有「API 安全」入口 —— 证书拿不到

实测证据：

- 超管登录 `1752422818` 后，「账户中心」左侧导航**只有「默认页面」一项**，
  没有「账户设置 / API 安全 / 员工账号管理」等子项。
- 直连 https://pay.weixin.qq.com/index.php/extend/apisecurity/index → **404**
- 直连 https://pay.weixin.qq.com/index.php/core/account/apiSecurity → **404**

官方文档口径：

- 申请商户 API 证书：超管登录**商户平台（直连模式）**或**合作伙伴平台（服务商模式）**，
  在【账户中心】→【API安全】→【商户API证书】申请。
- 设置 APIv3 密钥：超管登录，【账户中心 > 账户设置 > API安全】→「设置APIv3密钥」。

推断：`1752422818` 是**服务商模式下的特约商户**（商户平台显示服务商
`1749852372 腾讯云计算(北京)有限责任公司`），因此证书与密钥在**服务商平台**，
不在子商户自己的商户平台。**必须由服务商下发，或由服务商代签。**

### 卡点 2：个人版环境小程序未认证，且认证名额被体验版占用

- 个人版环境 `#/env/mp-auth`：小程序列表 **暂无数据（0 条）**。
- 页面提示：「同一账号下，只能使用一种认证方式。当前账号（`shizhang-pay-d2gz42qn06db00644`）
  环境已使用扫码授权认证过小程序，请先解除授权后再使用全托管认证。」
- 历史报错（体验版）原文：
  `[OperationDenied] 当前账号[wx562bcb6057346fb2]已绑定其他小程序，如需继续开通请前往[账号中心]换绑为当前小程序`

含义：**不解决认证，小程序端 `wx.cloud.callFunction` / `wx.cloud.callHTTPFunction`
连不上个人版环境**，集成中心建好了也调不通。

### 卡点 3：JSAPI / 小程序支付产品权限未开通

- 商户 `1752422818` 产品大全：`全部(4) / 未开通(4) / 申请中(0) / 已开通(0)`，
  仅 自动提现 / 运营账户 / 转账充值 / 自助清关，**无任何支付类产品，无自助申请入口**。
- 下单实测返回 `NO_AUTH`「该产品权限未开通」。

## 六、代码侧已确认的既有缺陷（待路线收敛后处理）

- `miniprogram/cloudfunctions/pay-create/index.js`：下单请求体**没有 `notify_url`**（微信 V3 必填）。
- 同上：下单成功后写 `db.collection('orders')`，此前在体验版环境因无文档库而失败；
  个人版环境已具备 `orders` 集合，这一点在个人版可用。
- `lib/wxpay.js` 是**直连单商户**写法（`mchid` + 自有私钥）。若最终为服务商模式，
  需改为 `sp_mchid + sub_mchid` 或用服务商证书，当前代码不成立。
- `miniprogram/config/index.js` 的 `cloudEnv` 仍为空串。**在认证修好前不要填**，
  否则 `wx.cloud.callFunction` 直接报错。
