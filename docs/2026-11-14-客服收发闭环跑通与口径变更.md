## 一、消息推送开启（不依赖后台界面）

官方 HTTP 接口即可配置，无需在「云开发控制台 → 设置 → 其他设置 → 消息推送」点选：

- 写入：`POST https://api.weixin.qq.com/tcb/setcallbackconfig?access_token=<token>`
- 读取：同前缀 `getcallbackconfig`，必须 POST（GET 返回 43002）；请求体传 `{}` 才返回数据，不传 body 会返回 `errcode:1`。
- access_token 由 AppSecret 经 `cgi-bin/token` 换取。

写入返回 `{"errcode":0,"errmsg":"ok"}`，回读结果：

## 二、云调用不可用 → AppSecret 回退通道

部署后先用假 openid 真实 invoke 探测权限，日志：

```
auto reply failed customerServiceMessage.send:fail invalid wx openapi access_token
```

判定该 CloudBase 环境未与微信侧打通云调用（`config.json` 里声明 `customerServiceMessage.send` 权限无效）。改为：

1. 函数内用 `WX_APPID` / `WX_APPSECRET`（函数环境变量）经 `cgi-bin/token` 换 access_token；
2. token 缓存进集合 `kf_token_cache`（文档 `global`，字段 `access_token` / `expire_at`，保留 5 分钟安全边界）；
3. 调 `cgi-bin/message/custom/send` 发文本。

再次用假 openid 验证，日志变成：

```
auto reply failed custom/send failed: {"errcode":40003,"errmsg":"invalid openid"}
```

说明 **token 与接口都已打通，仅 openid 无效**，符合预期。

| 项目 | 旧 | 新 |
|---|---|---|
| 主口径 | 客服由人工处理，通常 24 小时内响应；AI 仅辅助登记，不承诺自动回复或自动交付 | 本会话由 AI 自动应答并自动登记；极少数需人工判断的问题会转交跟进；AI 不承诺自动交付，交付进度以「我的订单」页状态为准 |

| 退款 | 由人工复核后 24 小时内回复 | 已自动登记，进度按订单状态回复；金额调整需人工复核 |

## 七、平台边界（必须记录）

1. **48 小时窗口**：客户最后一次发消息后 48 小时内才能主动触达。所谓「全主动化」只能做到「客户一开口就全自动闭环」，不能无触发主动推送。
2. **token 单例**：`kf_token_cache` 是全局单文档，多环境并发写可能互相覆盖；当前单环境无影响，扩环境前需改造。
3. **openid 明文**：`service_messages` 存 openid，需收紧集合权限。
4. **云调用缺失**：长期依赖 AppSecret 回退，密钥保管为本机 DPAPI 密文 + 云函数环境变量，仓库与日志无明文。
