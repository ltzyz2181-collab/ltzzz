# Deep 专用邮箱 qwe2181@126.com（2026-11-27）

## 决定
owner 决定给 Deep 单独开邮箱，使用 `qwe2181@126.com`；原 `qew2181@gmail.com` 因 owner 当前无外网登录条件作废。

## 实测通道
| 通道 | 结果 | 说明 |
|---|---|---|
| POP3 | ✅ 可用 | `pop.126.com:995`，9 封，只读，不删除 |
| SMTP | ✅ 可用 | `smtp.126.com:465`，认证 235 |
| IMAP | ⛔ 被拒 | 登录成功后 `SELECT` 返回 `Unsafe Login`（网易风控），不是口令错误 |

因此 Deep 的收件走 POP3，发件走 SMTP；`deep-mail-agent.py` 新增 `--transport pop3`。

1. 读共享箱 20 封项目邮件，自选 10 封正文，分诊 A 10 / B 6 / C 4（3 次调用，11034 tokens）。
2. 派单闭环自证：`#668` → 卡 `DEEP-SUPERAGENT-20261128-ISSUE-668-R2` → 队列 run `46095802545` success → PR `#675` 合并。
3. 用自己的邮箱发出两封：
   - 处理回执 → owner / 共享箱
   - 席位唤醒 → 豆包、WorkBuddy、GPT、共享箱，要求各自部署积压并按时回报
