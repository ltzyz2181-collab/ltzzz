**零成本探针（今后验证白名单只准用这个，别再拿假 appid 试）**：
```bash
APPID=$(grep -oE 'wx[a-f0-9]{16}' wrangler.wechat.toml | head -1)   # 必须从仓库取，禁止手抄
curl -s "https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid=${APPID}&secret=FAKE_PROBE_SECRET"
```
- `errcode=40164` + `invalid ip X.X.X.X` → appid 有效、**出口 IP 已被微信原样告知**（同时证明白名单没放行）。
- `errcode=40013 invalid appid` → **appid 本身写错了**，根本到不了 IP 校验；此时不能用它判断白名单（这是 2026-11-17 踩过的坑，见 `纠错记忆 C-20261117-05`）。
