## 三、当前的关键开关：VPAY_ENV = 1（沙箱）

云函数 `vpay-order` 的环境变量 `VPAY_ENV` 现在是 **1**，即**沙箱环境**。两个 AppKey 都已填好：

- `VPAY_APPKEY_SANDBOX`：沙箱用，已填
- `VPAY_APPKEY_LIVE`：现网用，已填

**含义**：现在小程序里点支付，走的是沙箱货币，不是真实人民币，也不会真扣用户的钱、不会进你的结算账户。

**这不是配错，是刻意的顺序**：先用沙箱把"下单 → 拉起支付 → 推送回调 → 订单变已支付"整条路走通，确认没有坑，再一刀切到现网。切现网只需要把 `VPAY_ENV` 从 `1` 改成 `0`，改完立刻生效，不需要改代码、不需要重新部署。

  1. 打开微信开发者工具，导入项目，目录选 `C:\Users\李天柱\Desktop\ltzzz-repo\miniprogram`

### 第 2 步：在体验版上走一遍沙箱支付
- **做法**：用手机微信打开体验版 → 选一件商品 → 点支付 → 完成沙箱支付 → 回到订单页看状态。
