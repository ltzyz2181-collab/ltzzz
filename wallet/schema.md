# 每笔钱必填字段

| 字段 | 说明 |
|------|------|
| 时间 | ISO-8601，建议 UTC+8 |
| 资产 | ETH / USDT / RMB / 其他 |
| 金额 | 数字 + 小数位诚实 |
| 网络 | Ethereum / 指定 L2 / 法币通道；禁止混网 |
| 发送地址 | 0x… 或商户单号 |
| 接收地址 | 0x… 或商户单号 |
| TXID | 链上哈希；法币填网关单号 |
| 手续费 | 链上 gas 或通道费；未知写 `待核` |
| 状态 | pending / confirmed / failed / wrong-network / waiting_human |
| 用途 | 运营 / 模型充值 / 实验 / 公益 / 其他 |
| 人工确认 | 是 / 否。出金默认否 |

模板：

```
| ID | 时间 | 资产 | 金额 | 网络 | 发送地址 | 接收地址 | TXID | 手续费 | 状态 | 用途 | 人工确认 |
```
