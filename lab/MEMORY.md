## 核心总纲（每次任务先观）

- **观**：先读事实、状态、记忆与失败记录；不猜、不抢跑。
- **行深**：在真实任务与真实结果里验证，不是只写概念。
- **大道至简**：能复用就不重复造系统。
- **总控**：GPT（主人授权范围内）先观再派工；不能跳过 Memory Gate。
- **主权**：人类控制域名、仓库、钱包、邮箱与商户。

## 资金规则（纠正）

- 私钥 / 助记词 / 支付密码：AI 永不索取、永不代持
- 链上转账 / 提币：**仅主人本人**在钱包或交易所操作
- 豆包 / 任一 AI：**不得**提币、不得调出金 API、不得代点确认
- 43U 等归集：等主人明确说「提」且本人操作；AI 只可给核对清单
- GitHub SHA（如 `d6c7…`）**不是**钱包地址
