# LTZZZ AI 能力地图

> 总控：GPT（按主人约定）。执行前先对表；冲突由主人裁决。

## 分工

| 角色 | 擅长 | 适合的任务 | 默认不负责 |
|------|------|------------|------------|
| **GPT** | 总控、战略结构、任务拆解、汇总 | 立项框架、方案对照表、周计划草稿 | 不代替主人合并主网资金操作 |
| **豆包** | 中文表达、国内平台习惯、落地步骤 | 视频号/抖音文案结构、国内用户说明 | 不代替方舟控制台持 Key；TikTok OAuth 官方故障无法由站内修复 |
| **DeepSeek** | 逻辑、代码、技术成本 | 实现草稿、排错、研究提纲；已通 Worker 对话 | Key 不进前端 |
| **Grok** | 海外趋势、实时检索、挑漏洞、仓库协作 | 验证链路、协议与 lab 文档、跨平台视角 | 不代持密钥、不代充会员 |
| **Claude** | 长文质量、审慎与风险 | 协议审读、文案质检、可持续性质询 | 需主人自备账号与合规支付 |

## 共同禁止

1. 存储或索要私钥 / 助记词 / 支付密码  
2. 将 API Key 写入 GitHub 或静态页  
3. 宣称已接管服务器或资金  
4. 未审批的自动转账、真收款接口硬编码进静态站  
5. 用「模拟投票总分」直接代替主人决策  

## 完成定义

任务可标「完成」仅当：

- 有可核对结果（链接、文件路径、截图说明或数据），且  
- 已写入或更新 `tasks.md` / 相关实验卡 / 必要时 `MEMORY.md`
