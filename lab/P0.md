# P0 验收

## ① Daily Cron

- toml：`[triggers].crons` 已取消注释
- 部署：Actions → Deploy Memory OS → job `deploy-daily-cron`
- 现网 `/health` 先证 Worker 活着；**真正 cron_id / execution_id** 只在 Cloudflare Dashboard → Workers → ltzzz-daily-automation → Triggers / Logs

本机补验：

```bash
npx wrangler deploy -c wrangler.daily.toml
npx wrangler deployments list --name ltzzz-daily-automation
npx wrangler triggers list --name ltzzz-daily-automation
```

## ② R2

R2 凭证**不写进代码**。绑定只在 wrangler：

```toml
[[r2_buckets]]
binding = "MEMORY_BUCKET"
bucket_name = "ltzzz-memory"
```

2026-09-21 Actions 实测：
- Token 能 `wrangler deploy` Worker
- Token **不能** `r2 bucket create`（API 10000 Authentication error）
- 因此 Gateway 带 R2 部署失败：bucket `ltzzz-memory` not found (10085)

主人要做：
1. Cloudflare 令牌加权限 **Account · Workers R2 Storage Write** 与 **Workers Scripts Edit**

3. 再跑 Deploy Memory OS
