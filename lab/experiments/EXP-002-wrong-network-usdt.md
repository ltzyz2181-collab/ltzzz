# 实验（教训）：USDT 误提 X Layer

- **ID：** EXP-002
- **日期：** 2026-09
- **状态：** 有结果（负面结果，作记忆）

## 观

支付/充值时网络必须与收款方支持列表一致。

## 行深（假设）

「地址格式都是 0x」不等于全链通用；X Layer 上的 USDT0 不会进入只监听其他链的交易所/支付账户。

## 实验（实际发生）

- 从 OKX 提 USDT，网络选 X Layer
- 收款方不支持 X Layer，账户无入账
- 链上 TX 可查

## 结果

- 资金在错误网络的目标地址语境下「到账」，业务账户不显示
- 正确动作：官方客服 + TXID；自助仅当本人控制该链地址私钥
- **禁止：** 把私钥给「代找回」

## 下一步

- 任何充值前核对方支持的网络列表
- 写入 MEMORY 禁区与失败表
