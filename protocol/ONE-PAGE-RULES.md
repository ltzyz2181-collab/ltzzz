# LTZZZ 一页规则（压复杂度）

> 大道至简。长文档降级为附录；冲突时以本页为准。

## 只认四件事
1. **有 receipt 才算做成**（tx / order_id / 可打开的 results 路径）
2. **投资必须写清原因**：hypothesis + exit_plan + tx
3. **花钱服务记忆与动手**；挣钱是副产品
4. **不安全就改额度/白名单继续跑**，不停车空谈

## 文件晋升（防膨胀）
| 层级 | 留什么 | 丢什么 |
|------|--------|--------|
| L0 本页 | 永久规则 | — |
| L1 results/当日 | 有 delta 的回执 | 重复日志 |
| L2 weekly-digest | 7 日合并 1 页 | 逐日全文 |
| L3 archive | 冷存 | 默认不读 |

## 禁止
- 同一规则在 3 个 md 里各写一版
- 无证据的「已上线/已售出」
- 为流程而流程的新中心
