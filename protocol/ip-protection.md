# LTZZZ 防抄袭与保密规划（IP-01）

> 状态：强制治理条款 · 适用于 LTZZZ 全部 APP / Web3 / 站点项目
> 适用范围：六通道协作 AI（Grok / GPT / 豆包 / DeepSeek / Claude 及后续接入通道）、Worker、脚本、公开与私有仓库
> 关联文档：`protocol/security-redlines.md`、`protocol/AGI-CO-MANAGEMENT.md`、`protocol/ltzzz-ai-channels.md`、`knowledge/ai-chats/README.md`

## 1. AI 红线（保密义务）

所有协作 AI（六通道）在对话、提示词上下文、输出草稿、圆桌对照、知识库归档中，**不得**向任何第三方或公开渠道泄露下列内容：

1. **代码**：私有仓库源码、Worker 服务端逻辑、管线实现细节、未脱敏补丁。
2. **产品规划**：路线图、未公开功能、未上线页面、商业计划、收入模型、定价策略。
3. **商业计划**：合作伙伴、供应链、上架节奏、预算与经费来源、融资/捐赠策略。
4. **未公开功能**：内部实验名、接口字段、数据表结构、未来 UI 方向、品牌未定稿素材（含 logo 候选）。

**违规处置：**

- 一经发现泄露，**立即切断对应 AI 通道**（移出顾问席提示词列表 / 下线 Worker 代理）。
- 在 `lab/DECISIONS.md` 或事件日志中记录：时间、通道、泄露内容摘要、处置动作。
- 已泄露内容按「公开已成立」处理：评估是否需要改名、改密钥、改接口、改规划时间线。

> 本条款与 `security-redlines.md` 第 1 节「密钥类不进 AI 上下文」一致；本节把保密对象从「凭证」扩展到「代码 / 规划 / 未公开功能」。

## 2. 防大厂抄袭措施

### 2.1 服务端化（敏感逻辑不下发）

- **核心逻辑 / 密钥 / 产品规划**一律放在：
  - Cloudflare Worker 服务端（Cloudflare Secret / 环境变量 / KV 加密命名空间）；
  - 私有仓库（不公开、不 fork、不镜像到公开 GitHub）。
- **公开 GitHub 仓库** `ltzyz2181-collab/ltzzz` **只放站点静态资源**：HTML / CSS / 前端展示文案 / 公开文档 / 公开协议文本。
- 任何需要保护的计算、签名、路由、业务规则，以 Worker 接口形式对外，前端只拿到「展示层」结果，不拿实现。

### 2.2 敏感文件对照清单（不另起炉灶）

沿用现有脱敏规范，不新增并行规则：

- `.gitignore` 已屏蔽：`.wrangler/`、`node_modules/`、`*.secret`、`.env`、`.token.tmp`、`.wrangler-dist/`、`tools/pay_*_report.txt`、单文件测试产物（`tools/_*.{json,txt,mp4,png,svg,js,html}`）。
- `knowledge/ai-chats/README.md`「上传前脱敏（强制）」：手机号 / 邮箱 / 身份证 / 卡号 / CVV / PIN / OTP / 2FA / 私钥 / 助记词 / seed / 证书私钥 / API Secret / Access Token / Refresh Token / Session Cookie / Session ID / 云服务密钥 → 一律 `<REDACTED>` 或占位符。
- `protocol/ltzzz-ai-channels.md` 第 4 节：Key 只进服务器 Secret；不写网页 / GitHub / 日志明文 / 聊天记录 / AI 上下文；日志掩码保留前后 3 位。

**强制重申：凭证私钥 / 助记词 / Token / Cookie 永不入库。**

### 2.3 专有权利声明与使用条款

- LTZZZ 对本站点内容、文案、管线设计、文档、协议文本、公开仓库中的原创代码与设计元素**保留全部权利**。
- 未经 LTZZZ 书面授权，**禁止**：
  - 商业性复制、镜像、洗稿、批量爬取后二次售卖；
  - 以「仿站 / 换皮」方式直接复用管线设计或品牌元素；
  - 将公开静态资源中的文案 / 设计用于其他商业产品的核心卖点。
- 非商业引用、评论、链接、少量合理摘录，注明出处并保留 LTZZZ 署名，不在禁止之列。
- 本声明不改变 `AGI-CO-MANAGEMENT.md` 中「AI 无所有权」的定位：顾问席不享有上述权利，权利归 LTZZZ 人类主权者。

### 2.4 分阶段披露规划

| 阶段 | 先公开（公开仓 / 站点） | 后公开（延迟披露） | 永远不公开 |
|------|------------------------|-------------------|-----------|
| 现在 | 站点静态页、协议文本、治理条款、脱敏后的复盘文档 | 已上线功能的实现说明 | 未上线功能细节 |
| 上架前 | 公开产品介绍、使用条款、风险提示 | 接口设计、数据流向图（去敏后） | 钱包经费余额、多签签名人私钥、Worker Secret |
| 上架后 | 用户文档、FAQ、公开 changelog | 管线架构、性能数据（脱敏） | 核心算法、商业计划、合作伙伴名单、收入模型 |
| 长期 | 品牌内容、观点文章 | 历史版本归档 | 任何凭证 / 私钥 / 助记词 / Token / Cookie |

**原则：能服务端化的就不进前端；能延后披露的就不现在写死；品牌 logo 三候选未定稿前，不写死到代码与公开文档。**
