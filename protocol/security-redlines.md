# LTZZZ 安全底线（任务十三，强制）

以下为**不可违反**的安全红线，适用于所有 Agent、Worker、脚本与文档。

## 1. 密钥类（一律不进以下位置）

API Key、Secret、私钥、助记词、seed、支付宝密码、支付密码、银行卡信息：
- ❌ 返回给创建者以外的任何第三方
- ❌ 写入 GitHub / 仓库
- ❌ 写入网页前端 / JS / HTML
- ❌ 写入聊天记录
- ❌ 写入日志明文（日志对 Key 一律掩码，保留前后 3 位）
- ❌ 写入 AI 上下文
- ❌ 写入云服务器明文文件 / 数据库明文

✅ 只允许：服务器端 Secret / 环境变量 / Cloudflare Secret / 硬件钱包 / 加密文件（密码另处保管）。

## 2. 资金控制

- 任何单一 AI 不得拥有完整资金控制权。
- 钱包 3/5 多签：单一个人、单一 AI、单一组织无法独立转移资金。
- 自动付款不得超预算；未经授权不得增加预算。

## 3. 行为

- 不绕过平台安全机制（验证码/3DS/风控/签名）。
- 不伪造支付或发布成功状态。
- 每笔资金/发布动作留下可审计记录。
