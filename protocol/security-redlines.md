# LTZZZ 安全底线（任务十三，强制）

以下为**不可违反**的安全红线，适用于所有 Agent、Worker、脚本与文档。

## 1. 密钥类（一律不进以下位置）

API Key、Secret、私钥、助记词、seed、支付宝密码、支付密码、银行卡信息：
- ❌ 返回给创建者以外的任何第三方
- ❌ 写入 GitHub / 仓库
- ❌ 写入网页前端 / JS / HTML
- ❌ 写入聊天记录
- ❌ 写入日志明文（日志对 Key 一律掩码，保留前后 3 位）
- ❌ 写入 AI 上下文
- ❌ 写入云服务器明文文件 / 数据库明文

✅ 只允许：服务器端 Secret / 环境变量 / Cloudflare Secret / 硬件钱包 / 加密文件（密码另处保管）。

## 2. 资金控制

- 任何单一 AI 不得拥有完整资金控制权。
- 钱包 3/5 多签：单一个人、单一 AI、单一组织无法独立转移资金。
- 自动付款不得超预算；未经授权不得增加预算。

## 3. 行为

- 不绕过平台安全机制（验证码/3DS/风控/签名）。
- 不伪造支付或发布成功状态。
- 每笔资金/发布动作留下可审计记录。

## 4. AI 保密红线（防抄袭与保密）

- 六通道协作 AI（Grok / GPT / 豆包 / DeepSeek / Claude 及后续接入通道）不得向第三方或公开渠道泄露：代码、产品规划、商业计划、未公开功能、未定稿品牌素材（含 logo 候选）。
- 核心逻辑 / 密钥 / 产品规划一律放 Cloudflare Worker 服务端与私有仓库；公开 GitHub 仓库 `ltzyz2181-collab/ltzzz` 只放站点静态资源。
- 凭证私钥 / 助记词 / Token / Cookie 永不入库（沿用 `.gitignore`、`ltzzz-ai-channels.md`、`knowledge/ai-chats/README.md` 既有脱敏规范，不另起炉灶）。
- 违反即切断对应 AI 通道并记录事件。
- 细则与分阶段披露规划见：**[`protocol/ip-protection.md`](./ip-protection.md)**。
