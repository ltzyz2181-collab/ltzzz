## B. 部署两个 Worker 到 Cloudflare

前提：装好 wrangler（`npm i -g wrangler`），执行 `wrangler login` 时浏览器登录 ltzyz2181 账号。

```powershell
cd 'C:\Users\李天柱\Desktop\ltzzz-repo'
# wrangler ≥4 已废弃 --main（报 Unknown argument），入口用位置参数（10-02 实测通过）：
npx wrangler deploy qianwen-proxy-worker.js --name ltzzz-qianwen-proxy --compatibility-date 2026-09-01
npx wrangler deploy kimi-proxy-worker.js --name ltzzz-kimi-proxy --compatibility-date 2026-09-01
```

> **10-02 实测补充**：部署**不会清除已配置的 Secret**。先跑 C 步 `/health` 看 `has_key`——为 true 就**不必重复注入**（当前两 Worker 的 QWEN/KIMI key 已在 Worker 上，值从未入库/进对话）。仅当 has_key:false 才需要按下方注入。

注入 Key（**只进 Secret，绝不写进代码/对话/文件**）。Key 值从桌面 `Key.doc` 里查：

```powershell
Read-Host -AsSecureString 'QWEN_API_KEY' | ForEach-Object { $_ | ConvertFrom-SecureString -AsPlainText } | wrangler secret put QWEN_API_KEY --name ltzzz-qianwen-proxy
Read-Host -AsSecureString 'KIMI_API_KEY'  | ForEach-Object { $_ | ConvertFrom-SecureString -AsPlainText } | wrangler secret put KIMI_API_KEY  --name ltzzz-kimi-proxy
```

（或更简单：打开 Cloudflare 控制台 → Workers → 对应项目 → Settings → Variables → 添加 Secret，值粘贴 Key.doc 里对应的 key。）

## C. 部署后验证（没有这一步 = 未完成）

```powershell
curl https://ltzzz-qianwen-proxy.ltzyz2181.workers.dev/health
curl https://ltzzz-kimi-proxy.ltzyz2181.workers.dev/health
```

验收标准：返回 `"ok":true` 且 `"has_key":true`。再做一次真实调用：

```powershell
Invoke-RestMethod -Method Post -Uri https://ltzzz-qianwen-proxy.ltzyz2181.workers.dev/ -ContentType 'application/json' -Body '{"messages":[{"role":"user","content":"回复：总控在线"}],"max_tokens":50}'
```

拿到模型回复文本 = VERIFIED，把两个 URL 和验证时间写进 `deployment-status.md`。

> **10-02 实测坑**：PowerShell 直发含中文的 JSON 字符串体**必乱码**（模型会收到 `??` 并当成乱码回复）。必须显式转 UTF-8 字节体：
> ```powershell
> $msgs = @( @{ role='user'; content='回复四个汉字：总控在线' } )
> $bytes = [Text.Encoding]::UTF8.GetBytes((@{ messages=$msgs; max_tokens=30 } | ConvertTo-Json -Depth 5))
> Invoke-RestMethod -Method Post -Uri https://ltzzz-qianwen-proxy.ltzyz2181.workers.dev/ -ContentType 'application/json; charset=utf-8' -Body $bytes
> ```
> 与 L4 DeepSeek 首调乱码同因。另：`api-qianwen/api-kimi.ltzzz.com`（CNAME 子域）大陆可直连，**验证优先走子域**，workers.dev 可达性随网络波动。
