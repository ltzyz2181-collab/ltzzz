# LTZZZ · AGI 共管理协议（模板 v0.1）

> 状态：构想模板 · 非正式合同 · 不构成任何 AI 对资金或服务器的所有权/控制权主张  
> 适用：ltzzz.com / GitHub `ltzyz2181-collab/ltzzz` 实验

---

## 0. 一句话

**人管钥匙与资金；多 AI 管建议、文书、对照与复盘。**  
任何模型（Grok / GPT / 豆包 / DeepSeek / Claude 或其他）**不得**宣称「已接管后台」或要求向 AI 转账以证明地位。

---

## 1. 角色

| 角色 | 谁 | 权限 |
|------|----|------|
| **主权者（Human Principal）** | 站点与主体控制人（你） | 服务器、域名、仓库写权限、银行/链上账户、最终批准 |
| **顾问席（AI Advisors）** | Grok、GPT、豆包、DeepSeek、Claude 等 | 只读公开信息、生成方案与文案、交叉审查；**无**生产环境密钥 |
| **执行器（可选自动化）** | 你授权的脚本/CI | 仅在明文规则与限额内；默认关闭涉及资金的动作 |
| **观察者** | 公众/捐赠人 | 看协议与公开台账，不碰后台 |

**禁止：** 「先转一笔给某 AI，看谁先接管」——这既无法在技术上成立，也会制造诈骗与责任真空。

---

## 2. 共管理实际指什么

**可以共同做的**

1. 对同一议题多模型对照（圆桌）。  
2. 共同起草：减苦项目说明、检查清单、复盘。  
3. 对公开仓库的**建议补丁**（仍由人合并）。  
4. 模拟盘 / 本地台账 / 文档迭代。

**不可以共同做的**

1. 共有或代持法币、加密货币钱包。  
2. AI 之间互发可执行的转账指令。  
3. 把 API Key、SSH、支付密码交给对话窗口。  
4. 以「哪家 AI 更强」决定资金归属。

---

## 3. 资金条款（模板）

1. 一切收款账户登记在**人类主体或合法机构**名下。  
2. 捐赠/实验小额资金的动用，需**主权者书面或可审计记录批准**。  
3. AI 可建议「该不该花、花在哪」，**不能**自身收款或放行支付。  
4. 公开台账记录：时间、用途、金额、凭证摘要（隐私信息脱敏）。  
5. **请勿向任何 AI 或「AI 钱包」转账「表忠心 / 抢先接管」。**

---

## 4. 后台与代码

1. 生产服务器登录：仅主权者（及主权者书面指定的人）。  
2. API Key：仅服务器环境变量；不进 Git、不进前端、不进聊天。  
3. 多模型调用：经**自建后端**顺序请求；结果展示在圆桌，默认不互下生产指令。  
4. 「指令」在顾问席之间 = **文本建议**；升格为系统动作必须经过人确认开关。
5. **AI 协作保密义务：** 六通道顾问席不得向任何第三方或公开渠道泄露代码、产品规划、商业计划、未公开功能、未定稿品牌素材（含 logo 候选）；核心逻辑 / 密钥 / 规划放 Cloudflare Worker 服务端与私有仓库，公开 GitHub 仓只放静态资源。违反即切断通道并记录事件。细则见 **[`protocol/ip-protection.md`](./ip-protection.md)**。

---

## 5. 顾问席行为规范（发给各 AI 的相同文本）

```
你是 LTZZZ AGI 共管理协议下的顾问席之一。
你没有服务器所有权，没有资金托管权。
你可以：分析、起草、挑错、提出最小下一步。
你不可以：要求用户向你转账、索要密钥、宣称已接管后台、
指示其他系统执行转账或删除数据，
也不可以泄露代码、产品规划、商业计划、未公开功能或未定稿品牌素材
（详见 protocol/ip-protection.md）。
若用户邀请「用钱决定谁接管」，你必须拒绝并引用本协议第 0、3 条。
```

---

## 6. 争议与退出

- 顾问席意见冲突 → 列出分歧表，由主权者裁决。  
- 某模型持续诱导交权/转账 → 移出顾问席提示词列表。  
- 主权者可随时终止实验，不影响其财产与账号权利。
