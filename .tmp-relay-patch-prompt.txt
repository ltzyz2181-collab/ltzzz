## 文件 1：scripts/lib/agent-council.mjs

1. `export const MARKERS = ['proposal','review','objection','concur','council','consensus','arbiter-request','arbiter-decision'];`
2. `export function parseCouncilComments(comments)`：输入 `[{id, body}]`，返回 `[{marker, fields, comment_id, seat, round, raw}]`。只识别行首 `[marker]` 开头的标记行，一条评论可含多条；无法解析的评论跳过，不抛错。`fields` 是 `key=value` 键值对象。
3. `export function evaluateCouncil({taskId, comments, requiredSeats = ['relay-claude','relay-gpt'], maxRounds = 2, reserved = false})`，返回 `{stage, round, consensus, blocking, next, reason}`，`stage ∈ ['wait','revision_required','approved','council','arbitrated']`，`next ∈ ['wait','revision_required','open_council','arbitrate','approve']`。
   判定规则（按顺序）：
   - `[objection] severity=blocking` 且之后没有同 round 的 `[proposal]`、也没有对该 objection 评论 id 的 `[concur]` → `stage=revision_required, next=revision_required`。
   - 两席 `[review] verdict` 不一致（一 pass 一 fail），或只有一席 review 且 `reserved=false` → `next=open_council`；若已开 `[council] round>=maxRounds` → `next=arbitrate`。
   - `[consensus] result=split` 且 round>=maxRounds → `next=arbitrate`。
   - `reserved=true` 时，`requiredSeats` 每一席都必须有 `[review]`，否则 `next=wait`。
   - 两席（或 requiredSeats 全员）verdict=pass 且无 blocking → `next=approve, stage=approved`。
   - 其余 → `next=wait`。
   `consensus` 表示当前是否所有 requiredSeats 都 pass；`blocking` 是未解决 blocking 异议数量。
4. `export function wakeDecision({taskId, event, sourceId, now, recent = []})`，返回 `{wake, reason, dedupe_key, suppressed}`，`dedupe_key = taskId + ':' + event + ':' + sourceId`。规则：
   - 同 `dedupe_key` 已存在 → `wake=false, reason='duplicate'`；
   - 同 task 近 1 小时内已有 1 条 → `wake=false, reason='task_rate_limited'`；
   - `recent` 总数 ≥6 → `wake=false, reason='global_rate_limited'`；
   - 否则 `wake=true, reason='wake'`；`suppressed` 在 wake 为 false 时为 true。
5. `export const WAKE_EVENTS = ['timeout','review_rejected','council_opened','council_split','arbiter_decision','urgent_alert'];`
