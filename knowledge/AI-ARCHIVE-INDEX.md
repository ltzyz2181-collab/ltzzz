## 三、文章生产分层

**一级：已经成文**
- 醒梦与时代场域
- 梦与魄相关文章
- 清醒/不空等现有文章

**二级：聊天记录已经足够形成完整长文**
- 魄户与睡眠
- 元神与梦
- 与神对话与东西方思想比较
- 谋生技能与灵魂价值
- AI共同治理

**三级：适合短视频，不宜直接写成哲学长文**
- TikTok OAuth
- Cloudflare部署
- GitHub/Pages
- 支付接口
- 视频引擎 fallback
- Windows故障处理

**四级：纯执行记录**
- API报错
- 重复部署
- 临时命令
- 单次测试结果

四级内容保留，但不占文章首页。

## 四、后续统一生产链

原始聊天 → 脱敏 → 会话主题 → 类目 → 核心观点 → 事实/体验/假说三分 → 长文 → 短文 → 视频脚本 → 视频 → 发布 → 数据回写。

每个可生产内容使用唯一 Content ID，例如：

`LTZZZ-20260917-A001`

同一主题产生的长文、短视频、封面、字幕、发布记录全部挂在同一个 Content ID 下。

## 五、审核底线

1. 不把个人体验写成已经被科学证明的事实。
2. 不把AI的推测写成用户已经确认的事实。
3. 不为了流量故意神秘化、恐吓化。
4. 修行文章保留东方概念原貌，同时标明哪些属于经典、哪些属于个人体验、哪些属于现代假说。
5. 技术文章必须区分“代码存在”“已部署”“已真实测试”“已上线生产”。
6. 钱包和支付文章不得出现任何真实私钥、助记词、API Secret、支付凭证。
