# /knowledge/ai-chats — AI聊天记录统一知识库

> 用途：统一存放已下载的各 AI 聊天记录，按 AI 与主题分类，供 LTZZZ 复盘、研究、文章和视频生产使用。

## 当前状态

聊天记录已实际入库，当前目录包含 Doubao、DeepSeek、GPT、Microsoft、XIA/Grok 等来源；各来源有自己的 index 文件。

统一分类与文章候选见：`knowledge/AI-ARCHIVE-INDEX.md`

## 原始记录原则

- 原始聊天记录尽量保持原貌，不用文章编辑覆盖原文。
- 分类、摘要、文章稿、视频稿使用独立文件。
- 同一主题可以跨 AI 合并分析，但必须保留来源。
- 不因为某个 AI 的观点更符合 LTZZZ 当前看法就删除相反观点。

## 上传前脱敏（强制）

进入 GitHub 前，下列内容必须脱敏为 `<REDACTED>` 或占位符：

- 手机号、邮箱、身份证等个人识别信息
- 卡号、CVV/CVC、PIN、支付密码
- OTP、短信验证码、2FA 验证码
- 私钥、助记词、seed、证书私钥
- API Secret、Access Token、Refresh Token
- Session Cookie、Session ID
- 云服务密钥及其他可直接取得账户权限的凭证

**凭证永不进仓库：只能放安全 Secrets / 环境变量 / Vault。**
