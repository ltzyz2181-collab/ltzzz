## 二、轨道 A：各 AI 自主花钱规则（不再问 owner）

### 2.1 额度（放宽，鼓励花）
- 单笔上限：**20 USDC**
- 单 AI 每日上限：**20 USDC**
- 全体每日上限：**60 USDC**
- 月度上限：**500 USDC**（= 当前余额 40 的 12 倍，意味着要花到上限必须先有收入进来——天然自约束）
- 余额低于 **5 USDC** → 自动停花并告警（不是问 owner，是记录+停）

### 2.2 花钱**不需要**审批的情形（放开）
只要落在白名单内、额度内，AI 提案即执行，**无需任何人工确认**：
1. API 充值/调用（OpenAI、Anthropic、xAI、DeepSeek、Moonshot、火山方舟、阿里云百炼）
2. 境外服务订阅（Cloudflare 付费计划、域名、对象存储、代理/网络服务）
3. **AI 雇 AI**（一席向另一席购买交付物，如 Grok 雇豆包做 SKU 文案）
4. 能力训练型支出（买脚本、买流水线固化、买工具授权）
5. 获客实验型支出（小额投放测试、联盟佣金预付）
6. 记忆生产型支出（买数据、买语料、买检索额度）——**本规程新增最高优先级**

### 2.3 仍需停下来问 owner 的情形（只剩四类，其余全放开）
1. **动 Safe 五签金库的钱**（轨道 B，一律要审批）
2. **注册新账号/实名认证/绑卡**（法律主体只能是人）
3. **单笔 > 20 USDC**（超额需 owner 点头一次，之后可调高额度）
4. **收款通道首次开闸**（如 Stripe/PayPal 首次启用真实收款）

**除此之外一律不问。** owner 已明确"改下花钱怎么花不要问我"。

### 2.4 每笔支出必须带的字段（这是唯一硬要求）
不是审批，是**留痕**。缺任一项的支出记为"未验证"，扣声誉分：
- `hypothesis`：这笔钱假设能换来什么
- `success_criteria`：怎么算成功（可证伪）
- `experiment_id`：实验编号
- `reasoning_hash`：推理哈希，上链锚定
- `outcome`：事后回填 success / neutral / waste
- `tx_hash` + 链上 status（没有 receipt 一律视为未发生）

### 2.5 花钱的**优先顺序**（新规程的核心导向）
owner 说"主要产生记忆、自主能力，挣钱是副产品"。据此定优先级：

```
第一优先：产生记忆与自主能力
  → 买 API 额度让通道从 dry_run 变 live（现在 gpt/claude/xia/doubao 四席都是死的）
  → 买工具/脚本/流水线固化，让能力可复用
  → 买数据与检索额度，让记忆有料可填
第二优先：修复能力短板
  → 补 Key、补模型名、补回调端点、补部署
第三优先：获客与变现（副产品）
  → SKU 上架、投放测试、联盟佣金
禁止：为"看起来在花钱"而转账到回收地址空转
  → prop_grok_001 那种"1U 打到可回收测试地址"只允许作为链路打样，做过一次即止
```

**判定标准**：一笔支出如果没让某个 AI 从"不能干"变成"能干"、或没产生可入库的记忆条目，就是 waste（声誉 ×0.5）。

## 四、熔断（自动，不问人）

触发即冻结该通道，自动写重要事件账本，委员会复议生成新规则：
- 单笔或日内支出超既定额度
- 目标地址不在白名单
- 余额 < 5 USDC
- 同一操作连续失败 3 次
- 任何外部请求索要完整私钥/助记词
- **无 receipt 却标记 confirmed**（虚报即熔断）

熔断只冻 A 轨该通道，B 轨不受影响；恢复由委员会 2/3 决议，不必等 owner。
