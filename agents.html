④ 让豆包真正帮你“部署/改网站”

  1. 在你的电脑准备 Node.js + Git。
  2. 安装火山引擎 Skills：npx -y @volcengine/skills-setup@latest。
  3. 在 Claude Code / 兼容 Agent 工具里启用火山引擎 Skills，并让模型使用 doubao-seed-evolving。
  4. 把本仓库 ltzyz2181-collab/ltzzz 克隆到电脑，让 Agent 在本地直接修改代码、运行检查、提交 Git。
  5. GitHub Pages 会从 main 分支继续发布。

官方近期文档显示 @volcengine/skills-setup 用于向 Claude Code 等开发 Agent 注入火山引擎 Skills；Doubao-Seed-Evolving 可通过 Agent Plan 接入 Claude Code。它和“把豆包 API 直接放进公开网页”是两件事。
